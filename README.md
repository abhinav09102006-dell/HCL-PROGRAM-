## **BULLDOG SECURITIES**

IP-Based Access Control and Web Traffic Monitoring System

**Project Description:**

BULLDOG SECURITIES is a beginner-level network security project designed to demonstrate how an IP-based access control system works. The project allows authorised IP addresses to access a protected server while blocking unauthorised IP addresses using Access Control Lists (ACLs).

The system is implemented using **Cisco Packet Tracer, XAMPP (Apache Web Server), and Wireshark**. Cisco Packet Tracer is used to simulate a network environment and configure router-based access control. XAMPP hosts a local website with IP-based access restrictions, allowing authorised users to receive an HTTP 200 OK response while unauthorised users receive a 403 Forbidden response.

Wireshark is used to capture and analyse network traffic, while router ACL counters and Apache log files help monitor successful and blocked access attempts.

The project demonstrates practical concepts of network security, IP addressing, packet filtering, web-server security, and network traffic monitoring in a controlled laboratory environment.

## **Key Features**

- IP-based access control and authentication through IP allow-listing.
- Router configuration using Cisco Access Control Lists (ACLs).
- Blocking unauthorised devices from accessing protected resources.
- Local web hosting using XAMPP and Apache.
- Real-time packet analysis using Wireshark.
- Monitoring HTTP 200 OK and 403 Forbidden responses.
- Logging and tracking authorised and unauthorised access attempts.

## **Technologies Used**

- XAMPP / Apache
- Wireshark
- IPv4, TCP, HTTP and ICMP
- HTML
- Cisco Router ACL Configuration
